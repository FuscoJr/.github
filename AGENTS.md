# Repository instructions

Read README.md and CONTRIBUTING.md before changing the shared workflow or default templates.

- Keep guidance generic and public-safe; exclude private project inventories, personal data and credentials.
- Preserve repository-specific overrides. Do not imply that default files are cloned or automatically loaded by agents.
- Use a task branch and a focused PR; the maintainer reviews and merges. Never merge or enable auto-merge.
- Verify form syntax, references and effective GitHub behaviour where possible; report UI checks that are still pending.
- Changes here can affect repositories without local overrides. Describe that account-wide impact in the PR.
